# AWSで電力データを収集・可視化する

技術同人誌「おうちの電力をIoT化・可視化してみよう」のAWS章で使用するサンプルコードです。
設定方法と処理の説明は、本の該当章を参照してください。

## ファイル一覧

|ファイル|内容|
|---|---|
|`lambda_function.py`|電力データの取得、前回値との差分計算、CloudWatchへの送信を行うPythonコード|
|`iam-policy.json`|Lambdaの実行ロールへ追加するIAMポリシー。`AWSアカウントID`を自分の12桁の番号へ置き換えて使用します|
