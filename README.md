# circle8-book-power-visualization-samples

技術同人誌『おうちの電力をIoT化・可視化してみよう』で使用するサンプルコードです。

## 書籍との対応

『おうちの電力をIoT化・可視化してみよう』
（2026年11月21日初版発行）に対応しています。

初版に対応するコードは、`v1.0.0`タグで公開しています。

## サンプルコード

- `09_aws/`
  - `lambda_function.py`
    - 第7章で作成するAWS Lambda関数
  - `iam-policy.json`
    - AWS Lambdaの実行ロールへ追加するIAMポリシー

詳しい設定方法と処理の説明は、本の第7章「AWSで電力データを収集・可視化する」を参照してください。

`iam-policy.json`の`{{AWSアカウントID}}`は、ご自身の12桁のAWSアカウントIDへ置き換えてください。
